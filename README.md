# ستوديو السكربت (Script Studio)

تطبيق جوال أندرويد احترافي لتحرير السكربتات وفحصها وتجهيزها.

## الميزات
- **محرّر سكربت** مريح على الجوال مع خط برمجي.
- **زر «فحص السكربت»**: يحلل السكربت ويخبرك باللغة، وعدد الأسطر، وماذا يفعل خطوة بخطوة، مع تحذير من العمليات الخطيرة.
- **زر «بناء التطبيق»**: يجهّز السكربت في حزمة موثّقة (script.txt + manifest.json) مع بصمة SHA-256.
- تصميم عربي (RTL) ودعم الوضع الليلي.

## الحصول على ملف APK للتثبيت على الجوال
1. ادفع التغييرات إلى GitHub (يبدأ البناء تلقائياً)، أو شغّل **Actions → بناء تطبيق أندرويد (APK) → Run workflow**.
2. بعد نجاح البناء، افتح صفحة التشغيل ونزّل الملف من **Artifacts**: `ScriptStudio-APK`.
3. فك الضغط ونزّل `ScriptStudio-debug.apk` على الجوال ثم ثبّته (قد تحتاج تفعيل «تثبيت من مصادر غير معروفة»).

## ملاحظة تقنية
الهاتف لا يستطيع تجميع APK من سكربت عشوائي (يتطلب أدوات مطوّر كاملة)، لذا زر البناء داخل التطبيق يحزّم السكربت ويوثّقه. أما ملف APK القابل للتثبيت فيُنتجه GitHub Actions.

## البناء محلياً
```
gradle :app:assembleDebug
```
المخرج: `app/build/outputs/apk/debug/app-debug.apk`
