# ستوديو السكربت (Script Studio) — الإصدار 2

تطبيق جوال أندرويد احترافي لإدارة مشاريع السكربتات: فحص، بناء، وربط تلقائي بـ GitHub.

## الميزات
- **تسجيل الدخول بـ GitHub**: اربط حسابك مرة واحدة برمز دخول، وبعدها تُنشأ المستودعات تلقائياً دون فتح الموقع.
- **إنشاء مشروع من خطوتين**:
  1. اسم المشروع + اسم التطبيق + صورته (من معرض الصور).
  2. السكربت + متطلبات البناء (الصلاحيات)، ثم يُنشأ المستودع على GitHub فوراً.
- **زر «فحص الكود»**: يحدد هل الكود **تطبيق/سكربت أم صفحة ويب**، لغته، ماذا يفعل خطوة بخطوة، وتحذيرات الأمان.
- **زر «بناء»**: يولّد ملف بناء GitHub Actions‏ (build.yml) وبيانات التطبيق (app.json) والوصف والبصمة.
- **إعدادات بأيقونة الترس** داخل كل مشروع: صورة التطبيق، اسمه، صلاحياته، واسم مستودعه.
- **رفع المشروع إلى GitHub**: السكربت وملف البناء والصورة والبيانات تُرفع إلى المستودع، ويعمل ملف البناء تلقائياً هناك.
- واجهة عربية (RTL) مع وضع ليلي.

## الحصول على ملف APK للتثبيت على الجوال
1. ادفع إلى GitHub (يبدأ البناء تلقائياً) أو شغّل **Actions → بناء تطبيق أندرويد (APK) → Run workflow**.
2. نزّل من **Artifacts** الملف `ScriptStudio-APK` وفك ضغطه.
3. ثبّت `ScriptStudio-debug.apk` على الجوال (فعّل «تثبيت من مصادر غير معروفة» إن طُلب).

## البناء محلياً
```
gradle :app:assembleDebug
```
المخرج: `app/build/outputs/apk/debug/app-debug.apk`
